# 📦 Logística na Prática

Landing page oficial do produto digital **Logística na Prática — Do Zero ao Controle de Estoque**.

## 📚 Sobre o projeto

Este projeto contém a página de divulgação do material digital **Logística na Prática**, desenvolvido para estudantes, iniciantes, estoquistas, auxiliares de logística e pequenos empreendedores.

O material aborda conceitos fundamentais de:

- Controle de estoque
- Curva ABC
- Armazenagem
- Movimentação de materiais
- Processos logísticos
- Organização de estoque
- Conceitos básicos de logística
